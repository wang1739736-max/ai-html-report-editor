# HTML 画板 · 版本记录

## v1.0 — 2026-09-22

首个完整版本，单文件 `html-editor.html`（约 250 KB，零依赖，双击即用）。
归档文件：`html-editor-v1.0-2026-09-22.html`

### 界面
- 玻璃拟态（Glassmorphism）皮肤：彩色模糊底 + 半透明磨砂面板 + 大圆角
- WPS 式**选项卡功能区**：开始 / 插入 / 文字 / 样式 / 视图 / 效率，一次只显示一组命令，可折叠（Ctrl+F1）
- 头部栏整合：品牌、项目名、保存状态、页面标签、保存 / 预览 / 导出
- 底部状态栏：操作提示 + 项目名 + 画板尺寸 + 选中计数
- **左侧快捷功能栏可自定义**：40 个功能任选，右键调整顺序 / 移除，`＋` 打开功能库

### 文件与项目
- 新建空白页 / 常用骨架 / **8 套模板**（作品集、落地页、演示稿、文档、简历、周报、定价页、邀请函）
- 打开 HTML、**保存到本地项目**（不下载）、导出 HTML（下载）、导出为…（改名下载）
- **多页面项目管理**：页面标签切换 / 双击改名 / 右键删除、页面管理面板、导出全部页面（含 index.html 导航页）
- 最近文件（5 个）、历史版本（10 个快照）、页面标题与描述、资源打包与路径检查

### 编辑
- 撤销 / 重做（80 步）+ **撤销历史下拉**（带中文步骤名，可一次退回多步；撤销会还原选中状态）
- 剪切 / 复制 / 粘贴 / 再制 / 删除、全页查找替换（Ctrl+F）、全选
- **自动保存**（改动后 2 秒）+ 刷新恢复提醒（右下角浮窗）+ 未保存离开提醒

### 插入
- 文本、图片（本地文件自动 base64 内嵌）、**8 种形状**（矩形/圆角/椭圆/三角/菱形/箭头/五角星/直线）
- **9 种内容块**（大标题/正文/按钮/链接/分割线/两栏/三栏/列表/表格），每项都有专属矢量图标
- 音视频（本地或 URL）、嵌入网页（iframe）、自定义区块库（存为区块，最多 30 个）

### 排版与对齐
- 拖拽绘制形状、8 向缩放手柄、顶部旋转手柄（Shift 吸附 15°）
- **移动与缩放都支持吸附对齐**：当前视口内所有可见元素的左/中/右、上/中/下 + 页面边缘中线 + 视口边界 + 手动画辅助线，参考线带数值标签
- `Shift` 轴锁定移动、`Ctrl` 临时关闭吸附、**`Alt`+单击设为对齐基准**（青框）
- 对齐与分布（相对页面 / 相对选区 / 相对基准元素）、方向键微调（Shift ×10）
- **视觉缩放 / 真实尺寸**自动判断：文档流元素缩放不挤动其他元素；`↺ 恢复` 一键还原原始状态
- **组合**（Ctrl+G）：整组一个选框、整体移动、整体等比缩放、双击进组编辑、Esc 退出
- 层级：置顶/上移/下移/置底；格式刷（单击一次 / 双击连续）
- 多选：Shift 或 **Ctrl 点选**、空白处框选

### 样式
- 字体 / 字号 / 加粗 / 斜体 / 下划线 / 文字色 / 填充色 / 段落对齐 / 行高 / 字间距
- 宽高、内外边距（四向）、边框（宽度/线型/颜色）、圆角、阴影、不透明度、背景图
- 图片：填充方式（适应/填充/拉伸/原始）、内部位置（`Alt` 拖动）、锁定宽高比、压缩、替代文字、丢失检查
- 表格：插行/插列/删行/删列、合并右/下、拆分、表头行、统一边框
- 布局与分栏：flex/grid 切换、分栏数、间距、水平分布、垂直对齐、自动换行、子项等宽
- **主题**：一键统计页面高频色并全页替换 + 统一标题/正文字体
- 链接与交互：链接 / 锚点 / 新窗口、悬停样式（导出后仍生效）
- 多端适配：电脑 / 平板 820px / 手机 390px 预览，元素可分端隐藏
- 导出检查：图片失效、外链、缺 alt、内容溢出、脚本保真提示

### 视图与代码
- 标尺与辅助线、尺寸提示（X/Y/宽高/角度/缩放比）
- 代码视图：HTML / CSS 双视图编辑、语法检查、定位选中元素源码
- 图层结构树：嵌套展示、重命名、锁定、隐藏、拖拽调序
