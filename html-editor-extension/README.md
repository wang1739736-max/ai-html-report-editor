# AI HTML 汇报修改台 · 浏览器插件

把当前网页 / 本地 HTML 文件一把变成可视化画板：像做 PPT 一样改文字、图片、形状和排版，改完导出干净的 HTML。

- 支持 **Chrome / Edge / 其他 Chromium 内核浏览器**（Manifest V3）
- 编辑全程在浏览器本地完成，**不联网、不上传**
- 不修改原网页：编辑器是覆盖在上层的独立界面，退出即还原

---

## 一、安装（开发者模式加载）

1. 打开浏览器，地址栏输入：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角的 **开发者模式 / Developer mode**
3. 点击 **加载已解压的扩展程序 / Load unpacked**
4. 选择本文件夹：`html-editor-extension`
5. 工具栏出现蓝紫色 **H** 图标即安装成功（可在扩展列表里点「固定」）

> **要编辑本地 HTML 文件（`file:///...`）**：进入扩展详情页，打开 **「允许访问文件网址」/ Allow access to file URLs**。否则点击图标不会有反应。

## 二、使用

1. **固定图标**：点浏览器右上角的拼图图标 → 在「AI HTML 汇报修改台」右侧点 **📌 图钉**，图标就会常驻工具栏，之后**一点即进**
2. 打开任意网页，**或**在浏览器里直接打开本地 HTML 文件
3. 点击工具栏的 **H** 图标 → 当前页面内容被载入编辑器（整屏覆盖）
   - 再点一次 = 关闭编辑器，回到原页面
   - 快捷键 **Alt+Shift+E** 同样可以打开（可在 `chrome://extensions/shortcuts` 修改）
   - 如果当前页面**不允许注入**（新标签页 `chrome://newtab`、扩展商店、PDF 等），会**自动新开标签页直接进入编辑器本体**，你仍然能立刻开始编辑
4. 像平时一样编辑：
   - 单击选中、拖动移动、拉角缩放、顶部圆点旋转
   - 双击改文字；`Shift`/`Ctrl` 点选多选，空白处拖框选
   - 功能区选项卡切换命令组（开始 / 插入 / 文字 / 样式 / 视图 / 效率）
   - 拖动与缩放都会**自动吸附**到其他元素边界，显示紫色参考线
   - 右侧面板：属性 / 图层 / 代码
5. **保存**：
   - `Ctrl+S` → 保存到本地项目（不下载文件，浏览器里随时可恢复）
   - **导出 HTML** → 下载一份干净的 .html 文件
6. 点头部的 **✕ 退出编辑** 回到原页面（原页面未被改动）

## 三、目录结构

```
html-editor-extension/
├── manifest.json          插件清单（MV3）
├── background.js          点击图标 → 注入内容脚本；注入失败则新开标签页打开编辑器
├── content.js             生成整屏遮罩 + 载入编辑器 iframe，把当前页面 HTML 交给编辑器
├── editor/
│   ├── editor.html        编辑器界面（由构建脚本生成）
│   ├── editor.css         编辑器样式（外置）
│   └── editor.js          编辑器脚本（外置）
├── icons/                 16 / 32 / 48 / 128 图标
├── tools/
│   ├── build-editor.js    由根目录 html-editor.html 生成 editor/ 三件套
│   └── make-icons.js      重新生成图标
└── README.md
```

### 为什么编辑器要拆成三个文件？

Chrome 扩展页面（MV3）的默认内容安全策略是 `script-src 'self'; object-src 'self'`，**禁止内联 `<script>`**。
如果直接把单文件版 `html-editor.html` 放进 `editor/`，界面能显示，但脚本完全不执行 —— 表现就是**所有按钮都没有反应**。
所以插件里的编辑器必须把样式和脚本外置。

### 更新编辑器本体（保持与单文件版一致）

在**工作区根目录**双击 **`同步打包.cmd`**，或执行：

```bash
node html-editor-extension/tools/sync-all.js
```

它会一次完成：生成 `editor/` 三件套 → 归档单文件版到 `versions/` → 重新打包 zip → **校验四者一致性**。

只更新编辑器、不打包时，也可以单独跑：

```bash
node tools/build-editor.js
```

改完记得回 `chrome://extensions` 点 **🔄 重新加载**。

## 四、常见问题

**点了图标没反应？**
- 若在**新标签页**（`chrome://newtab`）或扩展商店等受保护页面：现在会自动**新开标签页进入编辑器**；旧版请更新 `background.js` 后重新加载扩展
- 编辑本地文件时未开启「允许访问文件网址」→ 同样会自动改为打开编辑器，此时请在编辑器里用「文件 → 打开 HTML」选择文件

**改了代码后没生效？**
回到 `chrome://extensions`，点该扩展卡片上的 **🔄 重新加载**；再刷新页面。

**界面能打开，但所有按钮都没反应？**
说明编辑器脚本被 CSP 拦住了 —— 你装的很可能还是**单文件版**编辑器。请确认 `editor/` 目录下同时存在 `editor.html`、`editor.css`、`editor.js` 三个文件（用 `node tools/build-editor.js` 生成），然后重新加载扩展。

**编辑页面里有动画/翻页脚本，预览时不动？**
扩展页的 CSP 会连带影响编辑器里那个 srcdoc 预览框，页面自带的内联脚本不会执行（**导出不受影响**，脚本原样保留）。需要完整预览效果时，用「文件 → 导出 HTML」后在本机直接打开。

**想编辑本地 HTML 文件却打不开？**
在扩展详情页开启 **「允许访问文件网址」**；或直接打开单文件版 `html-editor.html`，用「文件 → 打开 HTML」。

**页面内容没载入？**
编辑器和页面之间有 1.2 秒兜底重试；如果页面用了严格的 CSP，或内容在跨域 iframe 里，可能取不到。此时可以直接用编辑器里的「文件 → 打开 HTML」选择本地文件编辑。

**导出后页面变样了？**
编辑器只改文字、图片、样式与位置，脚本和结构原样保留；可用「样式 → 导出检查」先体检（图片失效、外链、内容溢出等）。

**想更新编辑器本体？**
把新版 `html-editor.html` 覆盖到 `editor/editor.html` 即可（编辑器需保留 `?mode=ext` 相关代码块）。
