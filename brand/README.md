# 品牌说明 · AI HTML 汇报修改台

## 名字

**AI HTML 汇报修改台**

- **一句话定位**：AI 生成 HTML 的**最后一公里** —— 生成之后，交稿之前
- **解决的问题**：AI 生成的 HTML 汇报/网页总差一点点 —— 文案错字、数字没更新、图片比例不对、间距不齐、配色不统一。为了这几个小瑕疵回头改提示词重跑，代价太高；直接读代码改，门槛又太高。
- **产品角色**：`AI 生成 → 汇报修改台 → 交稿`，专做生成工具和交付之间的最后一步。
- **名字为什么这么直白**：用户搜的就是"AI 生成的 HTML 怎么改""汇报网页怎么改字"。把 **AI HTML / 汇报 / 修改台** 三个词直接放进名字，一眼知道它是干什么的。

## LOGO

**构成**：渐变圆角方块（画布）× 白色尖括号（AI 写的 HTML）× **金色圆点**（点上的最后一笔）。

三层含义压进一个图形：`< >` 代表 AI 产出的代码与网页，中间那颗**金点**就是"最后补上的那一下"。
即使缩到 16px 也认得出来，且图形本身不含文字，换名字不用换图标。

| 文件 | 用途 |
|---|---|
| `logo-mark.svg` | 主图标（矢量，任意缩放） |
| `logo-mark-512.png` / `logo-mark-1024.png` | 位图版本（文档、商店素材） |
| `logo-lockup.svg` | 横版组合：图标 + 产品名 + 定位语 |
| `make-brand-png.js` | 由代码重新生成位图（`node brand/make-brand-png.js`） |

浏览器插件图标（16/32/48/128）由 `html-editor-extension/tools/make-icons.js` 按同一套几何生成，与 SVG 完全一致。
